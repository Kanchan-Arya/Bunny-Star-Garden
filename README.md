# 🐰 Bunny Star Garden 🌟

Welcome to **Bunny Star Garden**, a cute little game built with Java! 🌸

Step into a magical garden, enjoy the adorable bunny theme, and have fun exploring a cozy gaming experience. This project was created as a fun way to learn Java game development.

## 🌷 Features

- 🐰 Cute bunny-themed gameplay
- 🌟 A charming garden-inspired experience
- 🎮 Simple keyboard controls
- ☕ Built using Java
- 🖥️ Runs as a desktop game
- 💖 A beginner-friendly Java project

## 🎮 Controls

Use the keyboard controls implemented in the game to play.

| Key | Action |
|---|---|
| ⬅️ / ➡️ | Move left / right |
| ⬆️ / ⬇️ | Move up / down |
| Space | Perform an action or start the game |

## 🚀 How to Run

### Requirements

- Java JDK installed
- Git (optional, for downloading the source code)

### Run locally

**1️⃣ Clone the Repository:**

   ```bash
   git clone https://github.com/Kanchan-Arya/Bunny-Star-Garden.git
   ```

**2️⃣ Open the project folder:**

   ```bash
   cd Bunny-Star-Garden
   ```

**3️⃣ Run the game:**

   ```bash
   java BunnyGame.java
   ```

If your Java version does not support running source files directly, compile and run it with:

```bash
javac BunnyGame.java
java BunnyGame
```
